## 1. 양자화 → θ̇ 잡음 증폭 (해석)

- pot 분해능 q = 0.3358°/count; 양자화 잡음 σ = q/√12 = 0.0969°; ADC 잡음 0.5 count 포함 σθ = 0.1939°
- 1 count 변화의 후진차분: q/Ts = **1.172 rad/s (67°/s)** → |K_θ̇|·q/Ts = **899 PWM**
- 백색잡음 가정 FD 표준편차 √2·σθ/Ts = 0.957 rad/s (양자화만: 0.479) → u 잡음 ≈ **734 PWM rms** (θ 위치 잡음 자체는 |K_θ|·σθ = 17.5 PWM)
- 엔코더 1 count 의 FD: 25.1 mm/s → |K_ẋ|·… = 51 PWM

### baseline sensor 로그에서 실측 (θ0=10°, t ≥ 2 s)

- 필터 없는 FD θ̇ 오차 std = **1.028 rad/s** (해석 0.957)
- FD+LPF 30 Hz θ̇ 오차 std = 0.418 rad/s
- θ 측정 오차 std = 0.213°
- u std = 187 PWM, RMS Δu = 280 PWM/step

## 5. 선정

규칙(사전 정의):
- nominal: 15 run 넘어짐 0, θ0=10° 정착시간 유한 → 정상상태 RMS Δu 최소
- 강건: 참값 상태(ideal)로 성공하는 불일치 케이스 전부에서 넘어짐 0 이고 RMS θ ≤ 1.5 × ideal 의 RMS θ → 그 케이스들 중 최악 RMS Δu ss 최소

- nominal 최적: **KF σa=(0.5,2)**
- 계열별 nominal 최적: LPF = FD+LPF 1Hz, REG = REG N=8, KF = KF σa=(0.5,2)
- 모델 불일치 포함 강건 최적: **없음 (규칙을 만족하는 추정기 없음)**
- 차선 (전체 케이스 넘어짐 합 최소 → 최악 RMS Δu ss 최소): **FD+LPF 5Hz** (넘어짐 합 1/90)
